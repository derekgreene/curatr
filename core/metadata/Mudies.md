## Mudie's Metadata

The file *book-mudies.json* is in JSON format, where each key corresponds to the unique book identifier from the British Library Microsoft Digital Collection. It contains the following fields:

Fields:
- mudies_id: identifier referring to unique entry in Mudie's Library Online
- mudies_title: the text of the title of the corresponding book in Mudie's Library Online
- mudies_authors: the author(s) of the corresponding book in Mudie's Library Online, stored as a list
